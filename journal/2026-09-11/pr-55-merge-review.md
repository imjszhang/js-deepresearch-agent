## CI 发现与修复

首次新 CI：`34609677353`，对应 `0cb6683`。Linux Node 22.23.2 全部通过；Node 20.20.2 的测试退出码为 0，所有必跑场景通过，lint/build/diff 也通过，但程序记录为 incomplete。因此保留 Draft，不能以测试退出码替代完整验收。

原因是 Node 20 的 `--test-force-exit` 在最终全局 `test:plan` 后结束进程，异步 reporter 没有机会执行 EOF 之后追加的结束标记。实际三批顶层完成数量分别为 150、8、321，与全局计划一致，但三个结束标记全部缺失。单测试最小复现也得到相同行为。

修复让 reporter 在收到最终全局计划时，将计划行与结束标记放入同一输出块，不依赖 EOF 或可选 summary 事件。消费校验同时要求结束标记前是全局计划，计划数量与实际顶层 pass/fail 数量一致。没有计划、错误数量、提前结束、结束后的残余测试事件继续不能通过。

新增断言纳入既有 V20/V02 必跑案例，覆盖真实强制退出子进程、事件源不结束时及时输出标记以及各种不完整边界。修复后的针对性测试在 Node 20.20.2 与 Node 24.18.1 均为 4/4 通过。没有减少测试或放松网络隔离。
